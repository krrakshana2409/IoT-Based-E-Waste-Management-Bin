The project includes two web-based dashboards developed using HTML, CSS, and JavaScript:

User Dashboard: Allows users to view their e-waste deposit details, track reward points based on deposited waste, and access reward redemption features.

Recycler Dashboard: Helps recyclers monitor e-waste collection details, track deposited waste, and view bin status for efficient waste management.

These dashboards are designed to support transparent e-waste collection, user engagement, and efficient waste segregation. Real-time sensor integration and backend connectivity are part of the planned implementation where not yet completed.
